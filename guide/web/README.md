# guide/web -- the CowMRP website

A clean academic-style site (home, getting started, examples, tutorial, API reference, scientific background, citation) built from the package itself.
It sits beside the older `guide/site/` build, which is untouched.

    python guide/web/build_web.py --examples    # run examples/*.py and content/quickstart.py, save output + figures, then build
    python guide/web/build_web.py               # rebuild from the saved output (fast); open guide/web/site/index.html

Needs `pip install -r guide/requirements-docs.txt` and the `plot` extra (matplotlib) for the figures.

| Where | What |
|---|---|
| `examples/*.py`, `content/quickstart.py` | the code shown on the pages and the source of the printed output (single copy) |
| `guide/tutorial.html` | the tutorial (re-wrapped in the site layout) |
| `content/*.html` | home, getting started, science text (model sizes are filled in from the built models) |
| `CITATION.cff` | the citation page |
| the five `*_METHOD_INFO` dictionaries | the Methods page (`methods.html`), read from the package at build time; `check_methods.py` checks that every key and value is on the page and that each long API value is hidden or kept by an explicit list (`HIDE_VALUES`, `KEEP_VALUES` in `build_web.py`) |
| `content/performance.html`, `content/performance_data.json`, `performance_page.py` | the Performance page: hand-written explanation, plus tables, sentences and four figures generated from the measured values in the data file (no number is typed in the text); the build stops if the data's model sizes differ from the package's. The page is also built into `guide/site/` by `guide/build.py` |
| `src/cowmrp` docstrings | the API reference (pdoc) |
| `theme/web.css`, `theme/web.js` | the one stylesheet and script (light/dark, copy buttons, outline, search) |
| `outputs/` | generated by `--examples` (git-ignored); `site/` is generated too |

Change an example script, run with `--examples`, and its page (code, output, figure) follows. If a script changed and `--examples` was not run, the build stops.
