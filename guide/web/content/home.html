Overview

A Markov reward process (MRP) is a list of states, the probability of moving from each state to each other state in one step, and a reward earned in each state. From those three things you get the expected value of a cow, how a herd is spread over states as time passes, and what replacing a cow is worth. In CowMRP the cow is described by three variables only, (lactation, days in milk, days pregnant), counted in steps of a time resolution you choose (month, week or day), and every probability and reward is a separate, documented module you can read and change.

It is written for researchers, graduate students and advisers who want to ask keep-or-replace and herd-projection questions of a model they can inspect, and for developers who want to build another animal domain on the same engine.

Choose the time resolution

The time step is a setting of the model: monthly (30 days), weekly (7 days) or daily (1 day). It is not a display option. One setting, COW_TIME_UNIT, rebuilds the model for the step you choose:

  • States. The same biological cow is a different, finer or coarser, state: the number of states grows from the thousands to millions.
  • Transition probabilities. Monthly rates are rescaled to the length of one step, so a weekly or daily step has its own transition matrix.
  • State rewards. The reward of a state is the rate (milk income, feed, reproduction costs and so on) integrated over the real days that one step spans, so a monthly state earns roughly thirty times a daily one.
  • Values. Expected values, herd projections and keep/cull comparisons are computed on that model; a finer step resolves events inside a month that a coarser step averages.

dim and dp are therefore step indices of the chosen resolution, not calendar days: the example cow (second lactation, 150 days in milk, 60 days pregnant) is state (2, 4, 2) at month resolution and (2, 149, 60) at day resolution. Durations such as the length of gestation stay in real days. The numbers in the table are measured from the three models when this page is built.

See Getting started for the same script run at all three resolutions, and the tutorial for what to watch for (a herd file is tied to its resolution; the day model is large).

Install

pip install cowmrp                 # engine + domains (numpy, pandas, scipy)
pip install "cowmrp[plot]"         # + matplotlib, plotly: dashboards and figures

New to Python? Follow the First steps, from installing Python to a projected herd and a KEEP / CULL table. Otherwise go to Getting started: a whole farm in a dozen lines, with the output it prints.

Design principles

  • The scientific model is the reference. The package changes how the model is reached, not what it computes; results are tested against saved outputs of the original scripts.
  • One engine, many domains. cowmrp.mrp knows no animal. Cow and youngstock sit on top of it, and a check enforces that the engine imports no domain.
  • Nothing is hidden. Every probability and reward is its own small module; the replacement cost is charged in an explicit comparison, not folded into the reward vector.
  • Fast by default. The exact expected distribution is the default mode; sampled modes are available but never run unless you select them.
