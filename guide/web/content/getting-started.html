Getting started

Install and run a whole farm

Five minutes from pip install to a projected herd.

Requirements

Python 3.10 or newer (tested on 3.12 and 3.13). The core needs numpy, pandas and scipy; figures and dashboards need the plot extra; the research scripts write Parquet files and need the parquet extra.

Install

pip install cowmrp
pip install "cowmrp[plot,parquet]"          # + figures, dashboards and Parquet output
pip install -e ".[dev,plot,parquet]"        # from a clone of the source repository

Choose the time resolution

The model can run at a monthly (30-day), weekly (7-day) or daily (1-day) step. Set COW_TIME_UNIT before Python starts. The script below builds the cow model and looks up one cow, second lactation, 150 days in milk and 60 days pregnant, so you can see what changes: the number of states and transitions, the cow's own (lactation, dim, dp) coordinates, and the reward her state earns per step and per day.

The same cow keeps her biology but gets different state coordinates, and the reward of a state is the reward of one step of that length. Per day the three agree closely, not exactly: a finer step resolves what a coarser step averages. A herd file made at one resolution is refused at another; the raw file (example_raw_herd_path(): days in milk and days pregnant in real days) can be loaded at any of them. The day model has about 2 million states, so use it on purpose.

Your own herd

A CSV with one row per cow and the columns lactation (1–10), dim_days (days in milk), dp_days (days pregnant, 0 if open) and optionally cow_id. Replace example_herd_path() by the file name. load_herd maps each cow to a model state and reports every record it cannot map, with its row and cow_id.

Five Jupyter notebooks that follow this workflow with a CSV of your own (cows, farm projection, individual rewards, youngstock, and your own domain on the engine) are in the user_examples/ folder of the GitHub repository. They are not part of the installed package; the Examples page shows how to get and run them.

Tutorial data. The example herd is synthetic: cows drawn from the model's own steady-state herd (seed 42). No real farm records are shipped.
