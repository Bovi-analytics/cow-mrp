Getting started

Install and run a whole farm

Five minutes from pip install to a projected herd.

Requirements

Python 3.10 or newer (tested on 3.12 and 3.13). The core needs numpy, pandas and scipy; figures and dashboards need the plot extra; the research scripts write Parquet files and need the parquet extra.

Install

pip install cowmrp
pip install "cowmrp[plot,parquet]"          # + figures, dashboards and Parquet output
pip install -e ".[dev,plot,parquet]"        # from a clone of the source repository

Your own herd

A CSV with one row per cow and the columns lactation (1–10), dim_days (days in milk), dp_days (days pregnant, 0 if open) and optionally cow_id. Replace example_herd_path() by the file name. load_herd maps each cow to a model state and reports every record it cannot map, with its row and cow_id.

Tutorial data. The example herd is synthetic: cows drawn from the model's own steady-state herd (seed 42). No real farm records are shipped.
