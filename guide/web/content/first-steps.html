First steps

Install CowMRP and run your first herd

A step-by-step guide for a first-time user: from installing Python to a projected herd and a KEEP / CULL table, with nothing assumed.

pipinstall cowmrp

CowMRP is on the Python Package Index (pypi.org/project/cowmrp). The steps below use the 200-cow synthetic herd that ships with the package, so you need no farm data to start. If you already know Python, the shorter Getting started page is enough.

Install Python

CowMRP needs Python 3.10 or newer; it has been tested on 3.12 and 3.13. Download Python from python.org/downloads. On Windows, tick Add Python to PATH in the installer, then open PowerShell and check:

Windows (PowerShell)

py --version

macOS / Linux

python3 --version

You should see a version number such as Python 3.13.x.

Create a project environment

Use a separate virtual environment, so CowMRP and its libraries do not mix with other Python projects.

Windows (PowerShell)

mkdir CowMRP_project
cd CowMRP_project
py -m venv .venv
.venv\Scripts\Activate.ps1

macOS / Linux

mkdir CowMRP_project
cd CowMRP_project
python3 -m venv .venv
source .venv/bin/activate

The prompt now starts with (.venv). If PowerShell blocks the activation script, skip it and call the environment's Python directly: use .venv\Scripts\python.exe wherever the steps below say python.

Install CowMRP

python -m pip install --upgrade pip
python -m pip install cowmrp

This is the basic installation. It installs the package and its three required libraries (numpy, pandas, scipy), and it is all you need to build the models, project a herd, write CSV tables and calculate KEEP / CULL. Plots, dashboards and the Excel workbook are optional extras that you add only when you want them:

Every step below works with the basic installation, except the one marked optional: dashboards, which says when to add the plot extra.

Check the installation

python -c "import cowmrp; print(cowmrp.__version__)"

Run your first herd

Create a file named first_run.py in the project folder and paste this code. It builds the cow model, loads the example herd, projects it 24 steps ahead and saves the results.

first_run.py

from cowmrp.data import example_herd_path
from cowmrp.model import build_model
from cowmrp.domains.cow.farm import load_herd, project_herd
from cowmrp.viz.farm import write_farm_outputs

# 1. Build the dairy cow model
model = build_model("cow")

# 2. Load the example herd (200 synthetic cows)
herd = load_herd(example_herd_path(), model)

# 3. Project the herd over 24 monthly steps
result = project_herd(herd, model, mode="expected", steps=24)

# 4. Save the result tables as CSV files (no plotting libraries needed)
write_farm_outputs(result, "farm_results", dashboards=False)

print("CowMRP run completed successfully!")

Run it:

python first_run.py

Output

3 independent variables, 0 derived variables declared.
All {{COW_STATES}} rows sum to 1.0 (within 1e-08)
CowMRP run completed successfully!

The first two lines are the model's own checks: every one of the {{COW_STATES}} states has transition probabilities that add up to one.

Find your results

A new folder farm_results appears next to the script:

CowMRP_project/
  .venv/
  first_run.py
  farm_results/
    distribution_summary.csv        cows by status, lactation, month in milk and stage: now and after 24 steps
    cow_values.csv                   one row per cow: her expected values (V, V_keep, ...) and status
    replacement_tracking_regular.csv     Dry / Open / Pregnant cows at each step: cows never replaced
    replacement_tracking_replaced.csv    the same for cows that entered through replacement

The CSV files open in Excel or in Python (pandas.read_csv). In distribution_summary.csv, current is the number of cows in each group today and predicted is the expected number after 24 steps, including cows that were culled and replaced on the way.

Optional: dashboards

To get the HTML dashboards as well, install the plot extra and write the outputs without dashboards=False. Nothing else in the script changes.

python -m pip install "cowmrp[plot]"

In first_run.py replace the saving line by:

write_farm_outputs(result, "farm_results")

and run the script again. Two files are added to farm_results: dashboard.html (a static dashboard) and dashboard_plotly.html (an interactive one). Open them in a web browser. Without the plot extra this call stops with a message that names the extra to install, before it writes anything.

Understand the projection settings

project_herd(herd, model, mode="expected", steps=24)
  • mode="expected" computes the expected distribution of the herd over the states, not one random simulated history. It is exact and reproducible. stochastic and monte_carlo are separate modes that you choose explicitly.
  • steps=24 is the number of model steps. At the default monthly resolution one step is 30 days, so 24 steps are 720 days, about two years. At weekly or daily resolution a step is shorter; see time resolution.

Prepare a CSV file with one row per cow:

cow_id,lactation,dim_days,dp_days

Then replace the example file in the script:

herd = load_herd("my_farm_data.csv", model)

load_herd maps each cow to a model state and reports every record it cannot map, with its row and cow_id: missing columns, duplicate cow IDs, invalid values and combinations that do not exist in the model.

Calculate KEEP / CULL

With a herd loaded, add:

from cowmrp.domains.cow.keepcull import keep_cull_table

table = keep_cull_table(herd, model, years=(1, 3, 5), offer=900)
print(table)

This needs only the basic installation. The table has one row per cow. For each horizon in years it gives value_1y, value_3y and value_5y: the break-even sale value, the offer at which keeping her and replacing her are worth the same. With an offer it also gives decision_<N>y (CULL when the offer is above the break-even value, otherwise KEEP), stable (the call is the same at every horizon) and rank_longest (1 is the weakest cow at the longest horizon).

Check the inputs before using the result. The offer of 900 is only an illustration: replace it with the net sale offer for your cow. The default prices are US values and several are provisional; the example herd is synthetic. See Defaults for every value, its source and how to change it for one run.

To work with the same comparison in Excel, with a live sale-offer column, install the excel extra and see the KEEP / CULL workbook.
